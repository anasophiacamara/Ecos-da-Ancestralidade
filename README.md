# Ecos da Ancestralidade

## Sobre o projeto

Este projeto consiste no desenvolvimento de um site sobre a presença e a representatividade da cultura negra na mídia, abordando filmes, séries, música, atores, atrizes e figuras importantes.

## Objetivo

O projeto foi desenvolvido para a **FECIP – Feira de Ciências da Escola Técnica do Rio de Janeiro**, como parte de uma atividade avaliativa.

A proposta tem como objetivo avaliar o desenvolvimento do site e os conhecimentos adquiridos pelos estudantes durante sua criação, considerando a organização do projeto, a aplicação dos conhecimentos técnicos, a apresentação e a compreensão dos conteúdos abordados.

## Conteúdos

- 🎬 Filmes e séries
- 🎵 Cultura negra na música
- 🎭 Atores e atrizes
- ✊🏿 Figuras importantes

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Finalidade

Além da avaliação, o projeto busca promover o conhecimento e a valorização da cultura negra, destacando sua influência e representatividade na mídia e na sociedade.
